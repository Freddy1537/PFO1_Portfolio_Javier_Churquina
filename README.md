## Sobre el proyecto

La landing fue desarrollada utilizando HTML y CSS, buscando una presentación personal sencilla, clara y con una estética relacionada con el desarrollo tecnológico.

El portfolio presenta mi perfil, una breve presentación personal, mis habilidades, algunos proyectos realizados durante mi formación y una sección personal relacionada con mis intereses dentro del desarrollo de software.

El contenido está organizado en diferentes secciones:

- Presentación personal.
- Sobre mí.
- Habilidades y tecnologías.
- Proyectos.
- Sección "Más allá del código".
- Formulario de contacto.
- Enlace al perfil de GitHub.

## Decisiones de diseño

Elegí una estética oscura y tecnológica porque considero que representa mejor mi perfil y mi interés por el desarrollo de software.

La paleta utiliza principalmente negro, gris y tonos metálicos, combinados con colores de acento como cyan, verde y naranja fluorescentes.

También busqué mantener una estructura visual limpia, utilizando tarjetas y diferentes niveles de jerarquía para separar la información.

El diseño responsive permite adaptar la presentación a diferentes tamaños de pantalla y dispositivos.

Para mejorar la interacción se incorporaron transiciones y animaciones CSS en distintos elementos de la interfaz.

Decidí no utilizar una fotografía personal en esta primera versión del portfolio, priorizando una presentación visual basada en el diseño y el contenido.

## Uso de Inteligencia Artificial

Durante el desarrollo de esta PFO utilicé **ChatGPT** como herramienta de apoyo.

### Herramienta utilizada

La herramienta utilizada fue ChatGPT.

La utilicé principalmente para:

- Revisar errores y problemas en el código, tanto en el HTML y CSS.
- Recibir sugerencias sobre la presentación visual.
- Resolver dudas relacionadas con Git y GitHub.
- Configurar y comprobar la publicación mediante GitHub Pages.

### Plan utilizado

Utilicé un **plan pago de ChatGPT (Go)** durante el desarrollo del proyecto.

### Experiencia previa

Ya contaba con experiencia previa utilizando ChatGPT como herramienta de apoyo en la correccion de errores en la estructura o la codificacion.

### Revisión y adaptación propia

La estructura y diseño durante el desarrollo fueron revisadas y adaptadas de acuerdo con mis propios criterios.

Las decisiones sobre mi presentación personal, las habilidades que quería mostrar, los proyectos incluidos, los enlaces utilizados, la estructura final de la página, la estética oscura y tecnológica y la combinación de colores fueron seleccionadas y revisadas por mí.

También revisé y modifiqué el código durante el proceso, realizando pruebas en Visual Studio Code mediante Live Server.

Posteriormente comprobé el proyecto publicado mediante GitHub Pages, verificando que la página se visualizara correctamente, que los estilos se cargaran y que los enlaces funcionaran.

La IA fue utilizada como herramienta de apoyo durante el proceso de aprendizaje y desarrollo, mientras que las decisiones finales, las modificaciones y la revisión del resultado fueron realizadas por mí.

Esta práctica me permitió integrar conocimientos de HTML y CSS con herramientas de desarrollo y control de versiones.

También me permitió comprender mejor el flujo de trabajo entre el desarrollo local, el control de versiones y la publicación de un sitio web.

Uno de los objetivos que me interesa seguir desarrollando es comprender cada vez mejor cómo se relacionan el frontend, el backend y las bases de datos para construir aplicaciones mas completas.
