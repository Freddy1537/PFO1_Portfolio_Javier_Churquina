# Portfolio Personal - Javier Churquina

## Sobre el proyecto

Este proyecto corresponde a la Práctica Formativa Obligatoria de la materia Desarrollo de Sistemas Web - Front End, de la carrera Desarrollo de Software.

La idea fue desarrollar un portfolio personal donde pueda presentarme como estudiante y desarrollador, mostrar algunas de las tecnologías que estoy aprendiendo y compartir proyectos que fui realizando durante mi formación.

Para el diseño elegí una estética oscura y tecnológica, utilizando principalmente negro, gris y cyan, con algunos detalles en verde y dorado.

---

## Sobre mí

Soy Javier Churquina y actualmente estudio Desarrollo de Software en el IFTS 29.

Me interesa especialmente la programación y el desarrollo de aplicaciones web. Una de las cosas que más me motivan es entender qué sucede detrás de una aplicación y cómo se relacionan las distintas partes que forman un sistema.

Durante mi formación fui trabajando con diferentes tecnologías, tanto para frontend como para backend, y continúo aprendiendo mediante proyectos y prácticas.
